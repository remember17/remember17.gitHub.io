Now Web 隐私政策

这份政策说明 Now Web 在提供账号、AI、笔记、看板、记账、时光和设置功能时如何处理信息。Now Web 与主要依赖本地设备或 iCloud 的 Now App 是不同的运行方式：你在 Now Web 中保存的内容会上传到 FiveHow 的服务器，以便登录后访问和同步。

本政策版本为 now-web-registration-2026-08-22。注册时，你需要主动勾选并同意本政策和 FiveHow 平台服务条款，系统会记录当时同意的版本和时间。AI 理解与自动整理是 Now 的核心能力，处理你主动提交的内容是完成你所请求服务的必要环节，日常使用中不会针对相同目的反复弹窗。你可以在设置中关闭未来的 AI 处理；若处理目的、方式或信息种类发生实质变化，或法律要求重新、单独取得同意，我们会再次说明并征求同意。

重要提示

  • Now Web 是云端账号产品：AI 对话、笔记、看板、记账和时光内容会保存到 FiveHow 的服务器，不是只留在浏览器或 iCloud。
  • AI 自动理解和记录是产品核心功能。你提交的文字和你明确引用的已有内容，会在完成请求所必需的范围内发送给当前启用的 AI 服务商。
  • 请不要提交他人的秘密、身份证件、完整金融账号、精确位置、医疗诊断等与你的记录目的无关的信息。若你主动提交可能属于敏感个人信息的内容，我们只为完成你要求的记录、整理或查询而处理。
  • Public V1 不支持图片上传，也不包含广告画像、向第三方出售个人信息或跨网站广告追踪。

由谁负责以及如何联系

Now Web 由 FiveHow 的个人开发者独立运营。你可以通过 support@fivehow.com 询问隐私、数据导出或账号删除事项。涉及账号数据的请求会先核验身份，避免他人代为操作。

会处理哪些信息

  • 账号与安全信息：账号 ID、已验证邮箱、登录方式、会话、必要的安全记录，以及你主动提供的显示名称或头像。
  • 你保存的内容：AI 指令与结果、笔记、看板、记账记录、时光记录及其必要的版本和状态信息。Public V1 不提供图片上传，因此当前不会通过 Now Web 接收图片文件。
  • 服务运行信息：请求路径、响应状态、耗时、IP 地址、浏览器或设备类型、错误类型和随机请求编号，用于排查故障、防止滥用和保护账号；私人正文不会作为常规应用日志内容。
  • 浏览器中的必要信息：登录凭据只保存在当前受保护的浏览器会话中；语言、主题等非敏感偏好可保存在浏览器本地。Now Web 不把账号访问凭据或私人正文写入 Web Storage。

为什么处理，以及依据是什么

  • 履行服务约定所必需：创建和保护账号、同步你保存的内容、执行你发出的增删改查操作、提供数据导出与账号删除。
  • 完成你主动请求的 AI 服务所必需：由当前 AI 服务商处理指令、明确引用的内容和完成请求所需的最少上下文。你可以在设置中关闭未来的 AI 处理；关闭后新的 AI 请求将停止，但不影响此前已经完成的处理。
  • 履行法定义务或保护安全：处理投诉、响应依法提出的请求、留存必要的安全审计证据、发现并防止欺诈、攻击和滥用。

AI 功能如何使用内容

完成注册后，Now Web 默认开启核心 AI 自动记录能力，不会在每条消息、首次创建笔记、首次记账或首次读取各模块时重复询问。系统只把当前指令、你明确选择的引用以及完成该指令确有必要的结构化上下文交给当前配置的 AI 服务商；不会默认把整个账号内容全部发送。AI 结果可能不准确，你仍应在重要决定、财务记录或不可逆操作前核对。删除、永久清理等高风险动作仍可能要求操作确认；这类确认是为了防止误操作，不是重复征求隐私同意。

你可以在设置中关闭全部 AI 处理，也可以关闭 AI 对笔记、看板、记账或时光中某一类内容的读取。关闭后，Now Web 不会在使用过程中反复请求开启；如需恢复，由你在设置中主动重新开启。关闭不会自动删除此前保存的对话或业务内容，你可以使用数据导出、单项删除或账号删除功能处理。

可能涉及的敏感个人信息

Now Web 不要求你提交身份证件、生物识别、宗教信仰、医疗健康、完整金融账户、精确行踪等敏感个人信息，也不会把这些信息作为注册条件。自由文本、记账或时光记录可能由你主动写入健康、财务、家庭或其他敏感内容；如确有记录需要，我们只在保存、同步、检索和完成你要求的 AI 自动记录所必需的范围内处理，并采用访问控制、传输加密、最小权限和审计等更严格措施。你可以选择不提交，或先去除不必要的身份信息。未来若新增专门收集某类敏感个人信息的功能，会在使用该功能前单独说明必要性和影响，并依法取得单独同意。

服务商与处理地区

账号和主要业务数据保存在中国杭州的 Home Region。FiveHow 仅在提供托管、数据库、邮件验证、备份、安全防护和你主动选择的 AI 功能所需范围内使用技术服务商。Apple、Google 或其他登录服务只在你选择相应方式时参与认证，并可能通过其分布在不同地区的基础设施处理必要信息。

  • 阿里云：用于中国境内的云服务器、数据库、对象存储、内容分发、安全防护和邮件验证码；处理完成相应基础设施任务所需的账号、网络、日志或邮件投递信息。
  • 当前启用的 AI 服务商（例如千问）：用于理解你提交的指令并返回结构化结果或文字结果；接收当前指令、明确引用内容及必要上下文。实际服务商、处理目的、地区和声明版本以设置页实时展示为准。
  • Google：仅在你主动选择 Google 登录时，用于验证身份；FiveHow 不申请 Gmail、Google Drive 或日历权限。

上述服务商通常按照 FiveHow 的指示或为完成你选择的独立服务而处理必要信息。FiveHow 不出售个人信息，不以交换利益为目的向第三方提供私人内容，也不把你的私人内容用于训练 FiveHow 自有的通用基础模型。若未来需要向新的独立个人信息处理者提供信息、发生依法定义的跨境提供，或处理方式需要单独同意，我们会先完成告知、影响评估和必要同意。

Cookie、浏览器存储与日志

Now Web 使用受保护的第一方 Cookie 维持登录，并在浏览器本地保存语言、主题等必要偏好。账号访问令牌和私人正文不会写入 Web Storage。Cookie 不是用于广告追踪；禁用必要 Cookie 会导致登录功能无法正常工作。服务器日志会记录请求路径、状态、耗时、IP、设备类型和随机请求编号，用于安全与故障排查，不把私人正文作为常规日志字段。

保存、导出与删除

  • 账号和业务内容通常在账号存续期间保留；回收站、运行日志、备份和安全记录按照各自必要期限清理、删除或去除身份信息。
  • 验证码等过期认证材料通常在过期后 1 天清理；过期刷新凭据通常在 7 天后清理；已结束的会话族、已投递通知和部分运行材料通常在 30 天后清理；为保证写操作不重复的幂等记录通常保留 90 天。
  • AI 服务调用的原始运行记录最多保留约 30 天，之后清理；已保存到账号中的对话和业务内容仍按账号内容规则保留。AI 服务商自身为安全、计费或履约保存的信息，按设置页所示声明及其适用条款处理。
  • 你可以在设置中申请数据副本。为防止他人冒领，导出请求需要当前账号确认；准备好的临时文件会在有限时间后删除。
  • 数据导出确认链接有效 48 小时；准备完成的临时导出文件通常在 72 小时后失效并清理。
  • 你可以在设置中申请删除账号。请求包含 7 天冷静期，期间可以撤销；期满后系统会清理可删除的账号资料和业务内容。因安全、审计或法律义务必须保留的少量记录会限制用途并去除直接身份信息。

如果法律规定的保存期限尚未届满，或立即删除在技术上难以实现，相关信息会停止除保存和必要安全保护以外的处理，并在条件满足后删除或匿名化。备份中的副本不会用于日常业务恢复以外的目的，并会按备份轮换周期被覆盖。

你的选择与权利

你可以在设置中查看登录设备、管理 AI 许可、申请数据副本或删除账号，也可以联系 support@fivehow.com 申请查阅、复制、更正、补充、删除或限制处理相关信息。我会在必要的身份核验后按照适用法律处理。

  • 查阅与复制：通过产品页面查看主要内容，并通过设置中的数据导出获取账号数据副本。
  • 更正、补充与删除：在对应模块修改或删除内容；无法自助处理时可通过邮箱提出请求。
  • AI 控制：在设置中关闭全部 AI 或单独关闭某类内容访问。关闭不影响此前已经完成的处理，也不会取消完成账号、安全、同步或你主动操作所必需的处理。
  • 注销账号：在 /settings/delete-account 发起；七天冷静期内可撤销，期满后进入不可逆清理。
  • 投诉与解释：可发送邮件至 support@fivehow.com。我们会核验身份、说明处理结果；你也有权依法向有管辖权的个人信息保护或网信主管部门投诉。

为保护账号，我们可能要求你从已登录会话、已验证邮箱或其他合理方式证明身份。对于明显重复、超出合理范围、可能损害他人权益或法律允许拒绝的请求，我们会说明原因。通常不会因你行使隐私权而收费；法律允许且请求明显超出合理范围时除外。

自动处理与 AI 结果

Now Web 使用自动化模型理解指令、提取结构化字段、生成摘要并建议写入目标。当前版本不会仅依据自动化结果作出对你具有重大权益影响的信用、就业、保险、医疗或类似决定，也不使用你的内容进行个性化广告。你可以修改或删除 AI 创建的记录；涉及不可逆操作时，产品会保留额外确认。

关于他人的信息

如果你在笔记、记账、时光或 AI 指令中填写他人的个人信息，你应确保有合法、正当的理由，并只提交完成记录所需的最少信息。请不要利用 Now Web 侵犯他人的隐私、名誉、知识产权或其他合法权益。

未成年人保护

Now Web 账号和互动功能目前不面向不满 14 周岁的儿童。监护人如认为儿童信息被误提交，请联系 support@fivehow.com，我会核验并协助处理。

安全与政策变化

FiveHow 使用传输加密、访问控制、最小权限、短时能力凭据、备份和安全检查等措施保护信息。没有任何网络服务能够承诺绝对安全；如发生可能影响你的安全事件，我会及时处置并按法律要求通知。若未来开放图片上传、Commerce 或其他会改变信息处理方式的功能，会先更新相关说明；需要单独同意时，会在启用前取得。

安全措施还包括将生产访问限制给必要角色、将支持访问绑定到明确账号和时限、对高风险操作保留审计证据、定期清理过期认证材料，以及对数据导出和删除进行身份确认。发生个人信息安全事件时，我们会采取止损、调查、修复和防止扩大等措施，并依法向有关部门报告或以站内提示、邮件等合理方式通知受影响用户。

政策更新与联系

我们可能因功能、服务商、法律或安全措施变化更新本政策。文字优化或不影响你权益的调整会直接公布；对处理目的、方式、信息种类或敏感信息处理有实质影响的更新，会在适用前以明显方式提示，并在需要时重新取得同意。历史版本和适用时间会保留可核对记录。隐私、数据权利或安全问题请联系 support@fivehow.com。
